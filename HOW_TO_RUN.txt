🎬 CineAI - How to Run Your Web Application
================================================================================

QUICK START (30 seconds):
------------------------

1. Open terminal/command prompt

2. Navigate to backend folder:
   cd cine-ai\backend

3. Run the app:
   python main.py

4. Open browser:
   http://localhost:8000

That's it! 🎉


WHAT YOU'LL SEE:
---------------

✅ Web interface with home screen
✅ Story prompt input
✅ Genre, tone, duration, aspect ratio selectors
✅ "Generate Video" button
✅ Real-time progress tracking
✅ Generated audio files with AI voices
✅ Background music matched to moods


USING THE APP:
-------------

1. On the home screen, enter a story prompt like:
   "A lonely astronaut discovers a glowing crystal on Mars"

2. Select your preferences:
   - Genre: Sci-Fi
   - Tone: Cinematic
   - Duration: 60s
   - Aspect: 16:9

3. Click "Generate Video"

4. Watch the progress (takes 2-3 minutes):
   - Phase 1: Generating story and characters (~60 sec)
   - Phase 2: Creating AI voices (~90 sec)

5. Check the outputs folder:
   ..\outputs\run_YYYYMMDD_HHMMSS\assets\

   You'll find:
   - audio_*.mp3 files (AI character voices!)
   - bgm_*.mp3 files (background music)
   - JSON files with story data

TROUBLESHOOTING:
---------------

Problem: "Module not found"
Solution: pip install -r requirements.txt

Problem: "Port 8000 already in use"
Solution:
  - Kill process using port 8000
  - Or edit .env and change PORT=8001

Problem: "API key not found"
Solution:
  - Check .env file exists in cine-ai folder (not backend)
  - Make sure API keys are filled in

Problem: "Frontend not loading"
Solution:
  - Make sure frontend folder exists
  - Check you ran "python main.py" from backend folder


ALTERNATIVE WAYS TO RUN:
------------------------

Option 1 (Windows):
  cd backend
  run_server.bat

Option 2 (macOS/Linux):
  cd backend
  ./run_server.sh

Option 3 (Manual):
  cd backend
  venv\Scripts\activate
  python main.py


API DOCUMENTATION:
-----------------

While server is running, visit:
http://localhost:8000/docs

This shows all available API endpoints and lets you test them!


TESTING WITHOUT WEB UI:
----------------------

Want to test the backend without the web interface?

Run: python test_pipeline.py

This runs Phase 1 and 2 from command line.
